# Изменения

## Установка одной командой — 2026-10-07

- Подсказка после установки учитывает оба состояния окна: «Включено» → «Закрыть»
  либо кнопка «Включить» → системное подтверждение. Наличие установленной копии
  само по себе не означает, что маршрутизация включена.
- Открытый `install.sh`: загрузка релиза с GitHub, закреплённый SHA-256 до
  распаковки, проверка подписи и установка без sudo.
- Существующая другая сборка не перезаписывается; обычная проверка первого
  запуска macOS сохраняется. `--no-open` и `--app-dir` для ручной проверки.
- Добавлены проверки установщика во временных папках и CI на обеих архитектурах.
- Бинарный файл приложения 1.1 и ранее опубликованные архивы не изменены.

## Инструкции для коллег — 2026-10-07

- README дополнен установкой по шагам, текстом системного подтверждения,
  проверкой после установки, отключением и объяснением названия кнопки HTML.
- Пакет `handoff` содержит обновлённую документацию и прежнее приложение 1.1.
  Исходники приложения, исполняемый файл и опубликованный тег `v1.1` не изменены.

## 1.1 — 2026-10-07

- Кнопка включения через публичный API NSWorkspace с системным подтверждением.
- Проверка назначения HTTP и HTTPS перед сообщением об успехе.
- Регистрация HTML/XHTML и передача локальных документов Safari.
- Универсальная сборка arm64 + x86_64 с целевой macOS 12.
- Подготовка к открытому распространению: лицензия MIT, исходники, документация,
  описание границ проверки и пакет для независимого аудита человеком или ИИ.

## 1.0 — 2026-10-07

- Преобразование обычных приглашений Zoom в `zoommtg://`.
- Safari для остальных ссылок и при отсутствии/ошибке запуска Zoom.
- 25 автоматических тестов обработки URL.

Открытая упаковка 1.1 не меняет логику приложения относительно ранее переданной
универсальной версии 1.1. Установленная копия при подготовке исходников не обновляется.

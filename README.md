# Zoom Link Router

Небольшое открытое приложение для macOS: обычные приглашения Zoom из почты,
календаря и мессенджеров открывает в Zoom, остальные ссылки — в Safari.
Интерфейс на русском языке. Лицензия [MIT](LICENSE).

Это самостоятельный проект, не официальный продукт Zoom или Apple.

## Сборка и тесты

Нужны Mac и Apple Command Line Tools либо Xcode со Swift. Сторонних зависимостей,
менеджеров пакетов и загрузки исполняемого кода в скриптах нет.
В папке проекта выполните:

```sh
zsh test.command
zsh build.command
```

Появится `Zoom Link Router.app`. Для сборки arm64 + x86_64:

```sh
zsh build.command --universal
```

Целевая версия — macOS 12+. Проверены запуск и назначение браузером на
Apple Silicon с macOS 26.6.2. Запуск на Intel и старых macOS пока не проверен.
Подробности и команды проверки — в [BUILDING.md](BUILDING.md).

## Включение

1. Перенесите приложение в «Программы». Finder может скрывать расширение `.app`.
2. Запустите его, нажмите «Включить» и подтвердите выбор в системном окне macOS.
3. Дождитесь сообщения «Готово». Zoom Workplace должен быть установлен отдельно.

Приложение становится обработчиком HTTP/HTTPS. **Обычные сайты всегда
направляются в Safari**; настройки другого браузера в версии 1.1 нет.
Клики внутри самого браузера обычно остаются в браузере.

Готовая сборка имеет локальную подпись ad hoc, без Developer ID и notarization.
Если macOS не может проверить разработчика, для полученного из доверенного
источника файла применима [инструкция Apple](https://support.apple.com/ru-ru/102445).
На управляемом рабочем Mac это может быть ограничено администратором.

## Отключение

Выберите прежний браузер в «Системные настройки → Рабочий стол и Dock →
Веб-браузер по умолчанию» (в macOS 12 — «Основные»). Затем приложение можно удалить.
Приложение не сохраняет прежний браузер и не восстанавливает его автоматически.

## Поддерживаемые ссылки

Автоматически преобразуются HTTP/HTTPS-ссылки на `zoom.us` или его поддомены
с путём `/j/` и 9–11 цифрами, необязательным завершающим `/` и параметрами
`pwd`/`omn`. Параметры сохраняются в исходном кодировании. Пример структуры:

```text
https://zoom.us/j/123456789?pwd=EXAMPLE
→ zoommtg://zoom.us/join?action=join&confno=123456789&pwd=EXAMPLE
```

Это синтетический пример; не используйте его для подключения к встрече.
Ссылки регистрации, вебинаров, организатора, персональные `/my/`, короткие URL
и неизвестные параметры направляются в Safari без изменения исходной ссылки.
Установка камеры, микрофона, SSO и зал ожидания остаются функциями Zoom.

Сам маршрутизатор не выполняет сетевых запросов, не пишет ссылки в журнал
и не хранит пароли. Он передаёт URL в локальный Zoom или Safari, которые
используют сеть и могут вести собственную историю. Подробнее — [SECURITY.md](SECURITY.md).

## Распространение и происхождение

Код можно изучать, менять и распространять по MIT с сохранением лицензии.
Исходная версия подготовлена с помощью ИИ по запросу пользователя; это
не независимый аудит безопасности. Автообновлений и фонового сервиса нет.

Архив для коллег содержит код, готовую сборку, `BUILD_INFO.json`,
`REVIEW_BUNDLE.txt` и `SHA256SUMS.txt`. Контрольные суммы помогают обнаружить
изменения файлов, но сами по себе не доказывают их происхождение или безопасность.
Сравнивайте их с копией, полученной по доверенному каналу.

История изменений — [CHANGELOG.md](CHANGELOG.md).

# Zoom Link Router

Небольшая открытая утилита для Mac: обычные приглашения на встречи Zoom из почты,
календаря и мессенджеров открывает сразу в Zoom. Все остальные веб-ссылки открывает
в Safari. Интерфейс на русском языке, лицензия [MIT](LICENSE).

**Версия 1.1 доступна для пробной установки.** Это самостоятельный проект,
созданный с помощью ИИ, а не официальный продукт Zoom или Apple.

## Кому подходит

- Mac с Apple Silicon (серия M) или Intel. Целевая версия — macOS 12 и новее.
- Zoom Workplace уже установлен.
- Вы хотите, чтобы обычные сайты открывались в **Safari**. Выбрать Chrome,
  Яндекс или Firefox для остальных ссылок в этой версии нельзя.

Утилита не работает на Windows, iPhone и iPad. Нажатия на ссылки **внутри**
Safari и других браузеров обычно остаются в браузере: утилита получает ссылки
из приложений, которые используют системный обработчик.

## Установка одной командой

Откройте **Терминал**, вставьте команду и нажмите Enter:

```sh
/bin/bash -c 'installer=$(curl -fsSL https://github.com/byvlasov/zoom-link-router/releases/download/v1.1/install.sh) && /bin/bash -c "$installer"'
```

Команда сначала целиком скачивает [открытый установщик](install.sh) с GitHub и
только после успешной загрузки запускает его. Установщик скачивает готовую
версию 1.1, сверяет SHA-256, проверяет подпись и копирует приложение в «Программы».
Если общая папка недоступна, используется `~/Applications`. `sudo`, Homebrew,
Git и инструменты разработчика не нужны. Zoom устанавливается отдельно.

Затем откроется приложение. Если написано **«Включено»**, всё уже настроено —
нажмите **«Закрыть»**. Если есть кнопка **«Включить»**, нажмите её и подтвердите
**Use “Zoom Link Router”** в системном окне. Если macOS не разрешит первый запуск,
используйте «Всё равно открыть» по инструкции ниже. Установщик сохраняет обычную
проверку скачанного приложения macOS и не отключает защиту системы.

### Короткая команда с разрешением запуска

Если доверяете сборке и хотите также снять предупреждение о непроверенном
приложении через Терминал, используйте явный параметр `--trust`:

```sh
zlr=$(curl -fsSL https://raw.githubusercontent.com/byvlasov/zoom-link-router/main/install.sh) && bash -c "$zlr" -- --trust
```

Команда целиком скачивает текущий установщик из открытого репозитория до запуска.
Параметр `--trust` снимает метку quarantine **только у проверенной копии Zoom Link
Router** после сверки архива и подписи. Это обход связанной с карантином проверки
Gatekeeper, а не проверка безопасности Apple. Общие настройки защиты macOS не
меняются. Без этого параметра обычное предупреждение сохраняется.
Отдельные команды `xattr`, поиск папки и `open` больше не нужны.

Повторный запуск оставляет идентичную установленную копию на месте.
Другую сборку он не перезаписывает: сначала переместите старую копию в Корзину,
затем повторите установку. Для смены версии автоматического обновления пока нет.

Для проверки без запуска приложения можно скачать `install.sh`, прочитать его
и выполнить `bash install.sh --no-open`. Дополнительный параметр
`--app-dir /абсолютный/путь` позволяет выбрать папку установки.

## Установка вручную: примерно две минуты

1. Скачайте и распакуйте `ZoomLinkRouter-1.1-handoff.zip`.
2. Перетащите **Zoom Link Router.app** в папку **«Программы» / Applications**.
   Finder может скрывать `.app` и показывать просто **Zoom Link Router**.
3. Запустите приложение двойным щелчком.
   Если написано **«Включено»**, настройка уже завершена: нажмите **«Закрыть»**,
   остальные шаги не нужны.
4. Нажмите **«Включить»**.
5. В системном запросе macOS выберите **Use “Zoom Link Router”**
   (использовать Zoom Link Router), а не **Keep “Safari”**.
6. Дождитесь сообщения **«Готово — Zoom Link Router включён»**.

Назначение утилиты браузером по умолчанию — часть её работы. Она сама не
показывает веб-страницы: передаёт подходящие приглашения Zoom, а остальное — Safari.
Ничего искать в списке браузеров системных настроек для включения не нужно.
Сообщение установщика о том, что версия уже установлена, означает только наличие
той же сборки. Включена ли обработка ссылок, показывает окно самого приложения.

### Если macOS не может проверить разработчика

Сборка имеет локальную подпись ad hoc, без сертификата Developer ID и проверки
Apple (notarization). Предупреждение при первом запуске возможно.

Если вы получили архив из доверенного источника и решили его открыть:

1. Сначала попробуйте запустить приложение.
2. Откройте **Системные настройки → Конфиденциальность и безопасность**.
3. Найдите сообщение именно о Zoom Link Router, нажмите **«Всё равно открыть» /
   Open Anyway** и подтвердите запуск. Названия кнопок зависят от версии macOS.

[Официальная инструкция Apple](https://support.apple.com/ru-ru/102445).
На рабочем Mac эти действия могут быть ограничены ИТ-администратором.

## Проверка после установки

1. Откройте обычную веб-ссылку из почты или мессенджера: должен запуститься Safari.
2. Откройте приглашение на **собственную тестовую встречу** Zoom из внешнего
   приложения: должен запуститься Zoom. Настройки звука, камеры, SSO и зала
   ожидания определяются Zoom.
3. Если что-то не подходит, отключите утилиту способом ниже.

Не используйте для реального подключения числовые примеры из тестов проекта.

## Почему у HTML-файла кнопка «Open with Zoom Link Router»

macOS может назначить системный браузер также приложением для HTML-файлов.
Тогда в окне просмотра файла отображается имя **Zoom Link Router**.
Это имя выбранного приложения, а не название HTML-документа.
При открытии такой файл будет передан Safari: содержимое HTML утилита не читает.

Если хотите открыть конкретный файл сразу в Safari, в Finder нажмите на него
правой кнопкой и выберите **«Открыть в программе → Safari» / Open With → Safari**.
Это разовое открытие без смены общих настроек.

**Не требуется переименовывать утилиту или менять приложение для всех HTML-файлов.**
На проверенном Mac с macOS 26.6.2 назначение Safari для всего типа HTML также
переключало HTTP/HTTPS на Safari. Если Zoom-ссылки снова пошли через браузер,
запустите Zoom Link Router и повторите «Включить» с системным подтверждением.

## Как отключить и удалить

1. Откройте **Системные настройки → Рабочий стол и Dock → Веб-браузер по умолчанию**.
   В macOS 12 настройка находится в разделе «Основные».
2. Выберите Safari или свой прежний браузер.
3. После этого Zoom Link Router можно удалить из «Программ».

Старый браузер утилита не запоминает и автоматически не восстанавливает.
Автообновления, фонового сервиса и запуска при входе в систему нет.

## Какие приглашения поддерживаются

Преобразуются HTTP/HTTPS-ссылки на `zoom.us` или его поддомены с путём `/j/`
и 9–11 цифрами, необязательным завершающим `/` и параметрами `pwd`/`omn`.
Пароль передаётся с исходным кодированием. Схематический пример:

```text
https://zoom.us/j/123456789?pwd=EXAMPLE
→ zoommtg://zoom.us/join?action=join&confno=123456789&pwd=EXAMPLE
```

Персональные `/my/`, вебинары, регистрация, ссылки организатора, короткие URL
и неизвестные параметры открываются в Safari. Если Zoom отсутствует или macOS
сообщила об ошибке его запуска, исходная ссылка также открывается в Safari.
Ошибку входа, возникшую уже внутри Zoom, утилита определить не может.

## Проверить код самостоятельно или с ИИ

Вся основная логика — в двух файлах Swift, всего 201 строка:

| --- | --- |
| [source/Router.swift](source/Router.swift) | Проверка и преобразование URL |
| [source/main.swift](source/main.swift) | Диалоги macOS, запуск приложений и завершение процесса |
| [source/Info.plist](source/Info.plist) | Объявленные URL-схемы и типы документов |
| [source/Tests/main.swift](source/Tests/main.swift) | 25 тестов обработки ссылок |
| [build.command](build.command), [test.command](test.command) | Сборка и тестирование |
| [install.sh](install.sh), [scripts/test-installer.sh](scripts/test-installer.sh) | Загрузка готовой версии, установка и проверки установщика |
| [scripts/review-bundle.command](scripts/review-bundle.command) | Генерация единого текста для аудита |
| [.github/workflows/checks.yml](.github/workflows/checks.yml) | Автоматическая сборка и тесты на GitHub |

Для ИИ загрузите отдельный файл **ZoomLinkRouter-1.1-installer-REVIEW.txt** по ссылке
в разделе «Скачать»: он включает установщик, его тесты и текущую документацию.
`REVIEW_BUNDLE.txt` внутри прежнего архива содержит исходный снимок для ручной
установки, без нового `install.sh`. В обоих файлах строки пронумерованы.
Готовый запрос для независимой проверки находится в [AI_REVIEW.md](AI_REVIEW.md).
Модель должна проверять утверждения автора по коду, а не принимать их на веру.

Для собственной сборки после чтения исходников нужны Apple Command Line Tools
либо Xcode со Swift. В папке проекта выполните:

```sh
zsh test.command
zsh build.command --universal
```

Скрипты сборки и тестов URL не скачивают зависимости, не запускают приложение
и не меняют системный браузер. Отдельный `install.sh` скачивает готовое приложение
и по умолчанию открывает его диалог настройки. Подробности — [BUILDING.md](BUILDING.md).

## Данные и лицензия

Сам маршрутизатор не обращается к сети, не пишет ссылки в журнал и не сохраняет
пароли встреч. URL передаётся Zoom или Safari; эти приложения используют сеть
и могут вести собственную историю. Утилита не помещена в App Sandbox.
Полное описание и ограничения — [SECURITY.md](SECURITY.md).

`BUILD_INFO.json` фиксирует происхождение сборки и снимка документации.
`SHA256SUMS.txt` содержит контрольные суммы файлов. Они помогают обнаружить
изменения, но не заменяют проверку источника получения архива.

Код можно изучать, изменять и распространять по [MIT](LICENSE).
[История изменений](CHANGELOG.md) · [Репозиторий](https://github.com/byvlasov/zoom-link-router).
